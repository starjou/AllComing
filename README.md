# AllComing

以 Claude AI 補助，做為熟悉 Cocos Creator 3D 開發的射擊遊戲專案。
3D 俯視角（Top-Down）自動防禦射擊遊戲。

## 遊戲介紹

玩家操控一座砲塔，自動瞄準並射擊向你不斷逼近的敵人。
擊殺敵人獲得金錢，用金錢升級技能，盡可能撐越久越好。

## 遊戲機制

- **自動瞄準**：砲塔自動鎖定最近的敵人並旋轉射擊
- **爆擊系統**：每發子彈有機率造成爆擊傷害
- **敵人生成**：敵人持續從場外生成並向砲塔逼近
- **HP 系統**：砲塔有血量，被敵人碰觸會受傷，歸零則遊戲結束
- **積分系統**：擊殺敵人獲得分數與金錢

## 技能升級

使用擊殺敵人獲得的金錢升級以下技能（升級費用隨等級提升）：

| # | 技能 | 效果 |
|---|------|------|
| 0 | 發射頻率 | 每級 +0.3 發/秒 |
| 1 | 子彈速度 | 每級 +2 |
| 2 | 子彈傷害 | 每級 +5 |
| 3 | 爆擊率 | 每級 +5% |
| 4 | 爆擊倍率 | 每級 +5% |
| 5 | 最大血量 | 每級 +20 HP |
| 6 | 每秒回血 | 每級 +1 HP/s |

## 技術

- **引擎**：Cocos Creator 3.8.8
- **語言**：TypeScript

## 腳本架構

| 腳本 | 說明 |
|------|------|
| `GameManager` | 遊戲狀態、數值管理（分數、金錢、HP、技能） |
| `TurretController` | 砲塔邏輯（瞄準、旋轉、射擊） |
| `BulletController` | 子彈移動與傷害判定 |
| `EnemyController` | 敵人 AI 與受傷邏輯 |
| `EnemySpawner` | 敵人生成管理 |
| `SkillManager` | 技能升級介面邏輯 |
| `UIManager` | 血條、分數、遊戲結束 UI |
| `CameraController` | 俯視相機控制 |
| `Leaderboard` | 排行榜顯示 |
